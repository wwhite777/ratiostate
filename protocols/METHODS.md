# Scientific method and numerical scope

This reader-facing summary is adapted from the archived curated scientific protocol (SHA-256 `818d615d7afaef4856b2615b655755e117a3de7ead52ab1fe473108b4fd57b49`). It preserves the numerical definitions but does not copy operational plans or claim an externally authenticated preregistration timestamp.

The study used one pretrained MNIST image model. Ten development test images were purposively selected (indices 0, 1, 2, 3, 4, 7, 8, 11, 18, 61). The fixed32 evaluation chose 32 further test indices by ranking eligible indices with SHA-256 of `RatioState-precision-extension-20260924-v1:index`, excluding those ten. Labels, pixels and outcomes did not enter the ranking. The fixed set is a within-model evaluation; training-set overlap is unknown. The saved row order and all selected pixel bytes are in `saved/fixed32/inputs/`.

Each image supplies 783 teacher-forced calls, with pixels 0–782 as inputs and pixels 1–783 as targets. A00 retains matrix and normalizer in FP32; A10 retains matrix in BF16 and normalizer in FP32; A01 reverses those roles; A11 stores both in BF16; `fp16_boundary` stores both in IEEE binary16; `bf16_pair_boundary` stores a two-word BF16 residual representation. Only the between-call retained state is quantized; intra-call graph arithmetic remains FP32. BF16 and FP16 round to nearest even. The exact numerical runner and scorer sources are under `inference/`. The score is an idealized sampler-implied conditional discretized-mixture negative log2 probability per predicted pixel, not a verified training objective.

The primary fixed32 paired contrast is A11−A10. Secondary contrasts are A01−A00, the left-associative interaction A11−A10−A01+A00, and A10−FP16. The original pointwise paired-image bootstrap uses PCG64 seed 20260924, 20,000 resamples and linear 0.025/0.975 quantiles. One image is the independent unit; 783 calls are not 783 independent images. The original sample size was an operational resource choice, not a power calculation. Missing cells are never replaced by zeros. Source hashes attest identity of local records, not historical timestamp authentication.

The retrospective selected-state diagnostic uses returned normalizer `r_t`, stored next-call feed `f_t`, effective increment `d_t=r_t−f_(t−1)`, and storage error `e_t=f_t−r_t`. In FP64, `H_t=sum_(s<=t)d_s`, `D_t=sum_(s<=t)e_s`, and `f_t=H_t+D_t`. Selected layers are 0 and 7, head 0, 32 coordinates. Image-level normalizer mass ratio sums `D_t` over the 64 selected coordinates and divides by the corresponding sum of `f_t`; zero denominators are missing. This ratio is not query-weighted and does not establish that storage loss causes score changes. Position windows are [0,128), [128,256), [256,512), [512,783). `analysis/analyze_saved_v2.py` regenerates the reported retrospective outputs from retained saved files.

The four-image fixed-feature readout decomposition uses the FP64 replay of saved FP32 mapped q/k/v as its reference, with additive epsilon. It compares saved numerator/effective denominator/output values and separates numerator, denominator and final output-rounding terms. Its exact formulas, half-scale normalization, undefined-zero rule and tolerances are in `saved/legacy/coupling/COUPLING_DIAGNOSTIC_CONTRACT_v1.md`, a curated numerical protocol. It is not a storage-only intervention and does not decompose new fixed32 full trajectories.

The separate packed-cache CPU record warmed 32 calls and measured six ordered rounds of 256 prefix calls per arm, resetting state per arm. It reports paired BF16/native and pair/native loop ratios and reachable retained backing-buffer payload bytes. It does not measure RSS savings, GPU latency or peak memory. The saved timing raw rounds are `saved/legacy/timing_raw.json`; no timing is rerun by the public quick check.

The original graph and data origins and exact hashes are in `ACQUISITION.md`. Fresh graph execution requires external model and runtime assets; saved-output replay does not. These records describe one model/checkpoint and do not establish broader-model generality, practical equivalence, or causal mediation.

The local scientific protocol, selected-index record, lock extract and packed-timing record are `fixed32_protocol.md`, `fixed32_selection.json`, `fixed32_lock.json`, and `packed_cache_timing_record.json`. These are curated public records with original source hashes; the selection JSON retains original bytes. None supplies external timestamp authentication.
