# Selected normalizer states

This directory contains the exact 192 fixed32 image-arm selected-state traces from the archived reproduction resource. Each run has 783 returned and next-call feed states for layers 0 and 7, head 0, 32 coordinates, with per-run manifests and completion records. BF16/FP16/pair encoded words are included where applicable. These selected arrays do not constitute a complete model checkpoint or all heads/layers. The inputs support the retrospective analysis command in `analysis/README.md`; the model graph and weights are not included.
