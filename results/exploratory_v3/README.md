# Retrospective score and normalizer-state outputs

These saved files report exploratory paired-score, position, absorption and cumulative storage-error summaries from 32 fixed32 images. The original numeric files remain byte-identical to the v5 supplementary archive. They do not establish a causal mediation result or a population-level equivalence margin.

`state_coordinate_ratios_v2.npz` (93,597,209 bytes) is intentionally omitted from Git because it is reconstructible from `state_inputs/runs/` by `analysis/analyze_saved_v2.py`; the exact command is in `analysis/README.md`. The other position and state-mass files are retained. `summary_v2.json` still records the omitted original output hash as lineage. The original numerical arrays and methodological limits are described in `results/README.md` and `protocols/METHODS.md`.
